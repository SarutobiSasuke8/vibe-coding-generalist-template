# Session Log Workflow

Metadata:

- trigger: after meaningful multi-file, architectural, debugging, or decision-heavy work
- inputs: goal, context, changes, verification, decisions, risks, follow-ups
- expected output: append-only session log
- verification: follow-ups use markdown checkbox tasks

## Steps

1. Copy `Templates/SESSION_LOG_TEMPLATE.md`.
2. Name the file with date and short topic.
3. Fill in goal, context, changes, verification, decisions, risks, and follow-ups.
4. Add the note to `Session Logs/_Session Logs Index.md`.
5. Promote durable facts or decisions into `Memory/` when useful.

## Handoff

Do not rewrite old session logs. Add a new note or appendix instead.
