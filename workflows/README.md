# Workflow Packs

Workflow packs are reusable operating rituals for AI-assisted development.

Each workflow should define:

- Trigger
- Inputs
- Steps
- Expected output
- Verification
- Handoff

Install only the workflows a project actually needs. The template includes common packs so teams can copy, adapt, or later install them through the CLI.

## Included Workflows

| Workflow | Use |
|---|---|
| `first-vertical-slice.md` | Build the smallest coherent user-visible path before expanding scope |
| `review.md` | Structured implementation or design review |
| `handoff.md` | End-of-session handoff |
| `retro.md` | Post-change or post-release retrospective |
| `todo-triage.md` | Convert loose tasks into a useful queue |
| `session-log.md` | Capture durable session memory |
| `release-prep.md` | Prepare a release candidate |
| `security-review.md` | Defensive security review |
