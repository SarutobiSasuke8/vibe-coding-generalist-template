# TODO Triage Workflow

Metadata:

- trigger: when `TODO.md` becomes stale, noisy, or overloaded
- inputs: current TODOs, roadmap, project brief, latest session logs
- expected output: actionable queue with clear next actions
- verification: each retained task is concrete enough to execute

## Steps

1. Remove completed or obsolete starter tasks.
2. Move immediate actions into `## Next`.
3. Keep uncertain ideas in `## Backlog`.
4. Convert vague items into specific tasks.
5. Add project labels only when the project is obvious.
6. Avoid turning strategy notes into tasks unless there is a concrete action.

## Handoff

Leave at most three `#next` tasks unless the project explicitly needs more parallel work.
