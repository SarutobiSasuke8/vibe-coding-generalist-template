Run a lightweight end-of-session retrospective on the work done in this conversation.

Steps:
1. Check `git diff HEAD` and `git status` to see what actually changed.
2. Review the conversation for decisions made, problems hit, and anything that felt awkward or slow.

Report in this format:

```
## What worked
- <approach, tool, or habit that helped>

## What slowed us down
- <friction point — unclear spec, repeated correction, missing context, etc.>

## AGENTS.md candidates
- <convention, rule, or preference worth codifying so future sessions don't repeat the same mistake or rediscover the same approach>

## Open questions
- <anything unresolved that should land in TODO.md or ROADMAP.md>
```

After the report, ask: "Want me to add any AGENTS.md candidates or open questions to the right file?"

Keep the retro honest and specific. Do not pad it. If the session was smooth, say so briefly and note only genuine candidates.
