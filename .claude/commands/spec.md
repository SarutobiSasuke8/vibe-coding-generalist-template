description: Draft a feature spec (goal, scope, acceptance criteria) before writing code
---

Read `AGENTS.md` and `docs/PROJECT_BRIEF.md`.

Before writing any code, create a spec for the requested feature or change. The spec must include:

1. **Goal** — what user-visible outcome does this create?
2. **Scope** — what will be built; what is explicitly out of scope?
3. **Acceptance criteria** — how will we know it is done?
4. **Implementation approach** — one paragraph describing the approach, no code yet.
5. **Risks** — what could go wrong or require a decision before building?

Write the spec in the chat. Do not write any code until the user approves the spec.

After approval, follow the operating loop in `AGENTS.md` to implement against the spec.
